2. 由 rpoB 对照反解 ε（rpoB 单拷贝，期望值只依赖基因组尺度）
==========================================================================
  实测：32354141 reads，rpoB 阳性 19691 条 = 609 /百万

  对假设的敏感性（row=细菌 reads 占比，col=平均基因组 Mb）：
               3.0       3.5       4.0       5.0
  f=1.0       0.48      0.56      0.64      0.80
  f=0.9       0.53      0.62      0.71      0.89
  f=0.8       0.60      0.70      0.80      1.00
  f=0.6       0.80      0.93      1.06      1.33

  取 f=0.9、G=4.0 Mb：ε = 0.710
  最保守（f=1.0、G=3.0 Mb）：ε = 0.479  <-- ε 的下限
  参考只覆盖 8 个物种，其他属的 rpoB 匹配不上 → 真实 ε 只会更高，
  所以这里得到的是**下限**。

  结论：ε 至少 0.48，不可能是我原来写的 0.15（差 3.2 倍）。

3. 用标定后的 ε 重算 hdcA 的 λ 与深度需求
==========================================================================
  λ_raw（携带率校正，未扣 ε）= 1.525 / 样本
    ε=0.479 -> λ_det=0.731；5 样本期望 3.65 条，实测 1 条，P(X≤1)=0.120
    ε=0.710 -> λ_det=1.083；5 样本期望 5.41 条，实测 1 条，P(X≤1)=0.029
    ε=0.500 -> λ_det=0.762；5 样本期望 3.81 条，实测 1 条，P(X≤1)=0.106

  λ_det=5 所需深度（ε=0.48（下限））：4310 万 reads/样本 = 6.8 个当前 run
  λ_det=5 所需深度（ε=0.71（居中））：2909 万 reads/样本 = 4.6 个当前 run

  对照：旧口径（ε=0.15）给 1.38 亿 reads / 22 run，偏高 3.2 倍。

  定性结论不变：λ_det 仍远低于 5，仍不可定量；只是「差多少」从 22 倍改成约 4 倍。
